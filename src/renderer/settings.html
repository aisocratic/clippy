Sessions

Every Claude Code session that has reported in. Click one to bring its buddy to the front.

Buddies

One buddy per Claude Code session, in the colour of that session. Pick who they are and how big they're drawn — every session uses the same choice.

Sprites are scaled by whole numbers, so they stay crisp. The buddy keeps this size whether or not a card is open.

Want more buddies? Grab a pack from openpets.dev/gallery ↗, then run npm run add-sprite-pack -- <folder>. Any folder under src/renderer/assets/themes/ with a theme.json shows up here.

Packs stay on this machine and keep their own licence — Clippy never redistributes them.

What Clippy answers

Each switch decides whether Clippy holds a hook open for you. Turn one off and that moment goes back to the terminal, exactly as if Clippy weren't running.

What Clippy can do

Everything a buddy does with a session, what triggers it, and — where it answers on your behalf — the exact JSON Claude Code receives.
