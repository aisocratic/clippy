Sessions

Every Claude Code or Codex session that has reported in. Click one to bring its buddy to the front.

Buddies

One buddy per coding-agent session, in the colour of that session. Every live session gets its own available face from the cast, including sessions running side by side in the same project.

Pixel sprites scale by whole numbers; SVG buddies stay smooth at every size. The buddy keeps this size whether or not a card is open.

Want more buddies? Grab a pack from openpets.dev/gallery ↗, then run npm run add-sprite-pack -- <folder>. Any folder under src/renderer/assets/themes/ with a theme.json shows up here.

Packs stay on this machine and keep their own licence — Clippy never redistributes them.

Updates

No auto-updater and no phoning home — checking is a button, and updating is git pull. This is the only place Clippy ever talks to something that isn't localhost, and only when you ask it to.
