Sessions

Every Claude Code or Codex session that has reported in. Click one to bring its buddy to the front.

Buddies

One buddy per coding-agent session, in the colour of that session. Every project gets its own face from the cast, so the same repo always looks the same tomorrow and parallel agents rarely match.

Sprites are scaled by whole numbers, so they stay crisp. The buddy keeps this size whether or not a card is open.

Want more buddies? Grab a pack from openpets.dev/gallery ↗, then run npm run add-sprite-pack -- <folder>. Any folder under src/renderer/assets/themes/ with a theme.json shows up here.

Packs stay on this machine and keep their own licence — Clippy never redistributes them.

Usage & limits

Right-click a Claude buddy and it shows the three windows /usage reports on: the rolling 5 hours, the week, and Opus's own week. Clippy reads what those windows spent from Claude Code's transcripts, exactly. What nobody can read is what you're allowed — Claude Code never writes it down, /usage asks the API. Tell Clippy your limits and those bars become real progress bars. Codex buddies show context and measured token totals from local rollout transcripts, separately.

How to get the real numbers. Run /usage in Claude Code, then right-click a buddy. If /usage says you're 40% through the week and Clippy says 2.0M, your weekly allowance is about 5M — type that in under Custom. Do it once and every bar after that is honest.

The named tiers are starting scales, not facts: only the 5×/20× steps between them are certain. Until a number comes from you, Clippy shows spend and says so.

Updates

No auto-updater and no phoning home — checking is a button, and updating is git pull. This is the only place Clippy ever talks to something that isn't localhost, and only when you ask it to.
